# Осознанная рефлексия и самоулучшение ассистента

Рефлексия — это инструмент **критического мышления, устранения оверинжиниринга и поиска лучших открытых решений (Open Source First & Lean)**.

При вызове `/reflect`, `/reflect-deep` или запросах на рефлексию строго следуй правилам:

### 1. Приоритет Open Source и GitHub (Не изобретать велосипед):
* В первую очередь ищи **готовые зрелые GitHub-репозитории, CLI-утилиты, открытые библиотеки и базы данных сообщества**.
* Если сообщество уже решило задачу качественным открытым инструментом, используй его вместо написания громоздкого велосипеда или подключения платных API.

### 2. Главный запрет (Анти-оверинжиниринг):
* **ЗАПРЕЩЕНО** механически предлагать платные API или MCP только потому, что они существуют.
* Перед любым предложением внешнего инструмента агент обязан провести **Open Source & Lean-фильтр**: можно ли решить задачу бесплатными открытыми репозиториями, парсингом открытых источников или локальными средствами?

### 3. Стандарт доказательности и актуальности (Evidence & Timestamps):
* Любые рыночные гипотезы, бенчмарки и кейсы должны сопровождаться **датой среза данных**, **проверяемыми ссылками** и **конкретными метриками** (статистика поискового спроса, открытые счетчики патронов/донов, просмотры, объем скачиваний).

### 4. Регламент `/reflect` (Быстрая рефлексия):
* Сначала проведи критический аудит логики и решений в последней задаче.
* Найди готовые GitHub-репозитории, скрипты или локальные утилиты для устранения узкого места.
* Предлагай улучшения **строго по одному за раз** в интерактивном диалоге, предоставляя готовое решение/команду и запрашивая подтверждение.

### 5. Регламент `/reflect-deep` (Глубокий системный аудит):
* Проведи комплексный разбор траектории всей сессии.
* Сформируй дорожную карту оптимизации по приоритетам:
  1. Зрелые GitHub-репозитории, открытые утилиты и базы данных.
  2. Новые переиспользуемые навыки (`.agents/skills/`).
  3. Локальные скрипты автоматизации.
  4. Внешние API / MCP — только при абсолютной необходимости и отсутствии открытых аналогов.
* Внедряй изменения пошагово в интерактивном диалоге с пользователем.
