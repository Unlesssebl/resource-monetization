# Skill: digital-storefront (Управление цифровыми витринами и Paywall)

## 🎯 Назначение
Этот навык регламентирует упаковку, лицензирование, ценообразование и дистрибуцию цифровых товаров через международные платформы (itch.io, GameBanana) и рублевые/криптовые каналы (Boosty, Telegram VIP).

## 📜 1. Стандарт коммерческой лицензии (Indie Game Friendly)

Каждый релизный ZIP-архив обязан содержать файл `LICENSE.txt` следующего содержания:
```
=== Commercial Indie Game License ===
1. Разрешено использование в коммерческих и некоммерческих играх/проектах.
2. Разрешена модификация, изменение цвета, масштабирование и нарезка.
3. ЗАПРЕЩЕНА прямая перепродажа исходных файлов как самостоятельного ассет-пака.
4. Указание авторства не обязательно, но приветствуется.
```

## ⚡ 2. Команды упаковщика релизов (CLI)

```powershell
# Упаковка коммерческого релиза текстур для itch.io
python scripts/rmon.py assets package \
  --source "data/assets/textures" \
  --slug "pbr_scifi_materials_vol1" \
  --title "Sci-Fi Seamless PBR Material Pack (4K)" \
  --price 4.99

# Генерация VIP токена доступа для клиента в Telegram
python scripts/rmon.py paywall token --tier vip_all_access --user 123456789 --ttl 48
```

## 🛡️ 3. Защита от исчерпания квот 8 ТБ Облака (Zero-Ban Standard)
1. **Тома по 4 ГБ:** Все крупные сборки разбиваются на тома (`.7z.001`, `.7z.002`) для обхода ограничений мобильных сетей и квот браузеров.
2. **Паролирование и шифрование заголовков:** Использование `-mhe=on` в 7-Zip скрывает структуру файлов от автоматических сканеров облаков.
3. **Ротация зеркал:** Ссылки распределяются между Яндекс.Диском и Google Drive, снижая пиковую нагрузку на один аккаунт.
