# Skill: market-evidence (Валидация рыночного спроса и пруфов)

## Назначение
Этот навык регламентирует сбор и оформление доказательной базы для любых бизнес-гипотез, кейсов монетизации и технических решений.

---

## 🎯 Стандарт «Триплет доказательств» (Evidence Triplet)

Каждое утверждение о спросе или кейсе монетизации **ОБЯЗАНО** содержать три элемента:

1. **🕒 Дата актуальности данных (Temporal Anchor):**
   * Всегда указывать месяц и год среза данных (например, `Срез: Август 2026`).
   * Запрещено приводить устаревшие данные без указания года.

2. **🔗 Прямые кликабельные ссылки на источники (Verifiable Sources):**
   * Ссылки на живые проекты (Patreon, Boosty, VK Donut, NexusMods, GitHub, 4PDA, официальные сайты).
   * Ссылки на открытые трекеры и поисковые ветки.

3. **📊 Твердые числовые метрики (Hard Quantitative Metrics):**
   * Поисковый спрос (запросов в месяц по Яндекс Wordstat / Google Trends).
   * Количество просмотров и страниц на форумах (4PDA, Reddit).
   * Количество звезд, форков и релизов на GitHub.
   * Количество активных платных подписчиков (патронов/донов) и тарифы.
   * Количество скачиваний на площадках (NexusMods, ModDB, GitHub Releases).

## 🛠️ Вспомогательный инструментарий агента

### ⚡ Главный комбайн валидации (всё в 1 команду):
```bash
python scripts/meta/validate_hypothesis.py --title "<Название>" --query "<Запрос>" --repo "<owner/repo>" --metric "<Метрика>" --source "<Ссылка>"
```

### Модульные утилиты:
1. **Оценка поискового спроса и ассоциаций (Google / Яндекс Suggest):**
   ```bash
   python scripts/meta/search_trends.py "<поисковый запрос>"
   ```

2. **Проверка репозиториев GitHub (звезды, форки, дата последнего релиза):**
   ```bash
   python scripts/meta/github_stats.py <owner/repo или URL>
   ```

3. **Проверка краудфандинга и авторов (Graphtreon / Patreon):**
   ```bash
   python scripts/meta/graphtreon_metrics.py <creator_name>
   ```

4. **Форматирование блока доказательств:**
   ```bash
   python scripts/meta/evidence_formatter.py
   ```
