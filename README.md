# Resource Monetization & Automation Hub

Проект по монетизации свободных вычислительных и облачных ресурсов (8 ТБ Cloud + 1 Gbps + Мощный ПК).

## Структура проекта
* `scripts/` — Скрипты автоматизации (Python, PowerShell / Bash) для работы с архивами, парсинга, синхронизации и бэкапов.
* `configs/` — Конфигурационные файлы (`rclone`, профили, пресеты сжатия).
* `data/` — Временные рабочие данные, кэши и локальные выгрузки (добавлены в `.gitignore`).
* `logs/` — Журналы выполнения фоновых задач.
* `docs/` — Документация, инструкции, аналитика спроса и идеи.
