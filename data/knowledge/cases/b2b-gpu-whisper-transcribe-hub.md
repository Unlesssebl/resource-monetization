# 🎙️ B2B GPU Whisper Transcription Hub

## 1. Суть бизнес-модели
Предоставление студиям видеомонтажа, подкастерам и инфобизнесу выделенного высокоскоростного API / Telegram-шлюза для пакетной расшифровки аудио в текст и субтитры (.srt) на наших свободных видеокартах (RTX 3050 / RX 6800 XT).

## 2. Механика работы и роль AI (95% Zero-Touch)
1. **Шлюз приема:** Студия присылает ссылки на видео или файлы в закрытый рабочий Telegram-чат/папку.
2. **GPU Обработка:** Whisper на RTX 3050 расшифровывает 1 час аудио за **3.5 минуты** (15x быстрее реального времени).
3. **Авто-выгрузка:** Бот возвращает `.srt` с субтитрами, `.txt` полный транскрипт и готовые таймкоды глав для монтажера.

## 3. Юнит-экономика
* **Тариф для студии:** Фикс **12 000 – 18 000 ₽ / месяц** за пакет до 50 часов расшифровки.
* **Себестоимость:** 0 ₽ (электричество ~150 ₽/мес).
* **2–3 постоянных B2B клиента:** **30 000 – 45 000 ₽ / месяц** чистого пассивного дохода.

## 4. Reality Check и риски
* **Слепая зона:** Качество распознавания специализированных терминов.
* **Решение:** Использование модели `medium` + пост-коррекция через Gemini Flash.
